Foliage Pass-Through v1.0
Supports Helldivers 2 Steam build 25480438 / EXE 1.8.46015.0.

Install Bingus Shared Loader v18 or newer and import this ZIP into Arsenal or
HD2MM. Enable and deploy both, then restart Helldivers 2.

What it changes: player rockets, missiles, launcher rounds and stratagem
ordnance (Eagle bombs, orbital and SEAF shells and more: 99 projectile types
that explode on impact) pass through tree canopies and bushes instead of
exploding in them. Trunks, limbs, the ground, rocks, buildings and enemies
still stop them. Enemy projectiles are unchanged. It gives these projectiles
the collision check the game already uses for plasma bolts and lasers: one
value per projectile type, once per game session, and nothing runs per frame.

On any other game build it does nothing and says so in the log:
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/FoliagePassThrough.log

To remove it, disable or remove it in the mod manager.
